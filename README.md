# 0050 成交量分析

單一檔案的互動式網頁（`index.html`），用於分析元大台灣50（0050）的成交量變化。
不需安裝任何東西——直接用瀏覽器開啟即可。

## 功能

- **資料來源**：於瀏覽器端直接呼叫臺灣證券交易所（TWSE）個股日成交資訊 API，
  逐月抓取近 26 個月資料（含節流與當日 localStorage 快取）；無法連線時自動改用
  內建示範資料，並在頁面上明確標示「示範資料（非真實行情）」。
- **KPI 卡**：最新收盤價與漲跌、最新成交量對 20 日均量的偏離、量比（÷5 日均量）、
  區間爆量日統計。
- **收盤價走勢**：折線圖，十字游標顯示開高低收、漲跌幅、成交量與量比。
- **日成交量與均量**：紅漲綠跌的成交量柱狀圖（台股慣例），疊加 5 日／20 日均量線，
  並以空心圈標記爆量日（單日量 > 20 日均量 × 2）。
- **量價關係**：單日漲跌幅 × 量比散佈圖，含價漲量增／價跌量增等四象限標示，
  滑鼠靠近即顯示該日明細。
- **月成交量**：各月量能加總，觀察長期消長。
- **其他**：區間切換（3 個月／6 個月／1 年／2 年／全部）、每日明細表格檢視、
  亮／暗主題（自動跟隨系統，可手動切換）、響應式版面。

## 使用方式

```
直接以瀏覽器開啟 index.html
```

或放上任何靜態網站主機（如 GitHub Pages）。

## 名詞定義

- **量比** = 當日成交量 ÷ 前 5 日平均成交量
- **爆量** = 當日成交量 > 20 日均量 × 2
- 成交量單位為「張」（1 張 = 1,000 股）
