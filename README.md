# 0050 成交量分析

互動式網頁（`index.html`），用於分析元大台灣50（0050）的成交量變化。

**線上版（GitHub Pages）**：https://supingsue.github.io/claude/

## 功能

- **資料來源**（依序嘗試）：
  1. `data/0050.json` 資料快照 — 由 GitHub Actions 於每個交易日收盤後（台北 15:30）
     自動向臺灣證券交易所（TWSE）抓取近 26 個月真實日成交資料並提交；
  2. 瀏覽器端再向 TWSE API 補抓最近兩個月，把資料更新到最新交易日；
  3. 沒有快照時（例如直接開本機檔案）改為全量向 TWSE 抓取（含當日 localStorage 快取）；
  4. 全部失敗才退回內建示範資料，並在頁面上明確標示「示範資料（非真實資料）」。
- **KPI 卡**：最新收盤價與漲跌、最新成交量對 20 日均量的偏離、量比（÷5 日均量）、
  區間爆量日統計。
- **收盤價走勢**：折線圖，十字游標顯示開高低收、漲跌幅、成交量與量比。
- **日成交量與均量**：紅漲綠跌的成交量柱狀圖（台股慣例），疊加 5 日／20 日均量線，
  並以空心圈標記爆量日（單日量 > 20 日均量 × 2）。
- **量價關係**：單日漲跌幅 × 量比散佈圖，含價漲量增／價跌量增等四象限標示，
  滑鼠靠近即顯示該日明細。
- **月成交量**：各月量能加總，觀察長期消長。
- **其他**：區間切換（3 個月／6 個月／1 年／2 年／全部）、每日明細表格檢視、
  亮／暗主題（自動跟隨系統，可手動切換）、響應式版面。

## 使用方式

直接造訪線上版，或以瀏覽器開啟 `index.html`。

## 自動部署

`.github/workflows/deploy.yml` 會在：推送到本分支、每個交易日台北時間 15:30、
或手動觸發（workflow_dispatch）時執行——抓取最新 TWSE 資料、提交 `data/0050.json`
快照，並部署到 GitHub Pages。

## 名詞定義

- **量比** = 當日成交量 ÷ 前 5 日平均成交量
- **爆量** = 當日成交量 > 20 日均量 × 2
- 成交量單位為「張」（1 張 = 1,000 股）
